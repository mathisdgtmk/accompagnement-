## Notes
- Ce qui n'est pas traduit : les textes qui font partie de l'image (sweat « BOY MOM », « AMERICA FIRST », panneaux Walmart, boîte « Glowstrike 4X »).
- Les répliques anglaises d'origine ont été retranscrites automatiquement : le sens est sûr (les mêmes phrases reviennent dans les 4 vidéos), mais les mots exacts et le minutage sont approximatifs.
- Les voix anglaises d'origine sont fortement atténuées sous la voix française, pas supprimées : une séparation voix/musique propre n'était pas possible ici. La musique de fond a des paroles en anglais qui restent donc audibles par moments.
- Voix : synthèse vocale française (Piper « siwis »), une seule voix pour tout.
