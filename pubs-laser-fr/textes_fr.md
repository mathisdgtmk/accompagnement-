# Pubs laser tag : versions françaises

Format : 720×1280 (9:16), 30 i/s, H.264 + AAC, ~14 s chacune.
Le texte à l'écran est incrusté dans la vidéo. Les emojis d'origine sont conservés.

**Audio :** aucune voix d'arrière-plan. Toutes les voix d'origine (réactions, cris, chant de la chanson) ont été retirées
avec un modèle de séparation voix/instruments. Il reste la musique instrumentale et les bruitages (lasers, portes, etc.),
plus une narration française qui lit le texte à l'écran.
